# Pratham Gupta | Personal Profile

A personal profile webpage built with HTML and CSS for the Web Technologies course (ICT 3131) at Manipal Institute of Technology, hosted on GitHub Pages.

## Live site

https://prathamg07.github.io/REPO-NAME/

## Sections

- Introduction with profile photograph
- About me
- Education
- Experience
- Projects
- Skills
- Interests
- Contact

## Files

- `index.html` : page structure and content
- `style.css` : all styling
- `profile.png` : profile photograph

## Built with

- HTML5 semantic elements such as nav, header, section, article and footer
- CSS with an external stylesheet, the box model, floats and positioning
- One media query so the layout stacks on small screens
- No JavaScript and no frameworks

## Run locally

Download the repository and open `index.html` in a browser.
